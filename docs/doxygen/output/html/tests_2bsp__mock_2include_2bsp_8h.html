Detailed Description

Replaces the real AVR bsp.h when building unit tests on the PC.

(HOST TEST STUB)

Provides a fake SREG and spies for BSP_disableInterrupts() / BSP_enableInterrupts() so tests can verify that critical sections are balanced and restore the saved interrupt state.

Put this directory BEFORE the real bsp.h in the include path.

180/******************************************************************************
181 * @brief Initializes and starts the CAN controller.
182 *
183 * @param cfg Driver configuration, must stay valid after the call.
184 *
185 * @details
186 * Resets the controller, clears all MObs, sets the bit timing, configures
187 * the MObs from the table and arms the RX MObs. It then enables the
188 * interrupts of the used MObs and enables the controller. Blocks until
189 * the controller has synchronized to the bus (11 recessive bits).
190 * Global interrupts must be enabled by the caller afterwards.
191 ******************************************************************************/
192void BSP_canInit(BSP_canConfig_t const * cfg);

195/******************************************************************************
196 * @brief Handles the CAN interrupt.
197 *
198 * @details
199 * Called from the CAN_INT vector. Clears the general interrupt flags,
200 * reports general errors, then serves every MOb with a pending interrupt:
201 * a received frame is read and passed to onRx and the RX MOb is re-armed,
202 * a finished transmission is passed to onTxDone. Do not call from
203 * application code.
204 ******************************************************************************/
205void BSP_canISRHandler(void);

247 *
248 * @param mobNmb MOb to configure.

250 * @param IdentifierTag 11-bit filter tag.
251 * @param IdentifierMask 11-bit filter mask, 1 = bit is compared.

254 * @details

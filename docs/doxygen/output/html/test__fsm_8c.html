Detailed Description

Unity unit tests for the FSM and the event queue (fsm.c / fsm.h).

Test strategy

  • Two dummy states (stateA, stateB) and an initial pseudo-state log every call (state id + signal). Tests then compare the call log with the expected sequence, e.g. a transition A -> B must give A(event), A(EXIT), B(ENTRY).
  • bsp.h is replaced by a host stub (see stubs/) so the queue can be tested without AVR hardware. The stub counts interrupt disable/enable calls and records the restored SREG value.
  • eventLoop() never returns, so a state handler leaves it with longjmp() when it receives STOP_SIG.

Not tested: EvtQueue_pend() on an EMPTY queue. It busy-waits forever and needs a second thread/ISR to be released.

\doxysubsection{Detailed Description}
Replaces the real AVR bsp.\+h when building unit tests on the PC. 

(HOST TEST STUB) 

Provides a fake SREG and spies for \doxylink{tests_2bsp__mock_2include_2bsp_8h_ad0740f954a2011d919ad14afbacf64ff}{BSP\+\_\+disable\+Interrupts()} /\+ \doxylink{bsp_2megas64m1_2include_2bsp_8h_a3acf0a6be9bd59753f8d3dfe6fcd9f5d}{BSP\+\_\+enable\+Interrupts()} so tests can verify that critical sections are balanced and restore the saved interrupt state.

Put this directory BEFORE the real bsp.\+h in the include path.

\doxysubsection{Detailed Description}
Unity unit tests for the FSM and the event queue (\doxylink{fsm_8c}{fsm.\+c} /\+ \doxylink{fsm_8h}{fsm.\+h}). 

Test strategy
\begin{DoxyItemize}
\item Two dummy states (stateA, stateB) and an initial pseudo-\/state log every call (state id + signal). Tests then compare the call log with the expected sequence, e.\+g. a transition A -\/\texorpdfstring{$>$}{>} B must give A(event), A(\+EXIT), B(\+ENTRY).
\item bsp.\+h is replaced by a host stub (see stubs/\+) so the queue can be tested without AVR hardware. The stub counts interrupt disable/\+enable calls and records the restored SREG value.
\item \doxylink{group___a_p_p___f_s_m_ga9ada9a864987666e9e3332d539cc0de7}{event\+Loop()} never returns, so a state handler leaves it with longjmp() when it receives STOP\+\_\+\+SIG.
\end{DoxyItemize}

Not tested:\+ \doxylink{group___a_p_p___f_s_m_gab09810cb7c1ae4f5da98e823b0c909b1}{Evt\+Queue\+\_\+pend()} on an EMPTY queue. It busy-\/waits forever and needs a second thread/\+\+ISR to be released.
